# Siege Team Builder
This project enables users to strategically build a team of five operators from Ubisoft’s Tom Clancy’s Rainbow Six Siege. Once a team is selected, the application generates ratings across five key categories, along with an overall team effectiveness score. Additionally, users can interact with a top-down view of any in-game map using a drag-and-drop interface to position operator icons. These features are designed to support strategic planning and team coordination for competitive play.
